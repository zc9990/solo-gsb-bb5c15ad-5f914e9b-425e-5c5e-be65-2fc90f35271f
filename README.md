# 盲杯三角测试台

三杯两同一异的三角盲测工具：主持人创建 A/B 样品场次，系统为每位参与者均衡分配六种呈样顺序（AAB / ABA / BAA / BBA / BAB / ABB）并生成场次内唯一的三位盲码；参与者提交一次异样杯位与 1～5 信心值；场次关闭后公布总命中率及按顺序、按信心分组的结果。

技术栈：Node.js + Express + SQLite（better-sqlite3）+ 原生 HTML/JS 前端。

## 启动（一条命令）

```bash
docker compose up --build
```

依赖安装与数据库表结构初始化均已纳入启动流程，无需额外步骤。

## 访问地址

| 入口 | 地址 |
| --- | --- |
| 首页（创建 / 加入场次） | http://localhost:3000/ |
| 主持台 | 创建场次后自动跳转，URL 形如 `http://localhost:3000/host/<主持口令>` |
| 参与者 | `http://localhost:3000/join/<加入码>` |

端口：`3000`（宿主机）→ `3000`（容器）。

## 配置（环境变量）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 服务监听端口 |
| `DB_PATH` | `/app/data/triangle.db`（容器内） | SQLite 数据库文件路径；Compose 已挂载命名卷 `triangle-data` 持久化 |

修改端口示例：`PORT=8080 docker compose up --build`（需同步调整 compose 的端口映射）。

## 使用流程

1. **主持人**：首页输入样品 A、B 的真实名称 → 创建场次，获得**主持口令页面**与 **6 位加入码**。
2. **制样**：主持台展示每位参与者的制样映射（杯位盲码 → 样品 A/B），按此倒样贴码。关闭前主持台仅展示制样映射与人数，不含任何作答与汇总。
3. **参与者**：凭加入码进入，输入昵称领取 3 个盲码杯位；页面只显示盲码，不泄露 A/B 映射、正确杯位与任何汇总。选出异样杯位并选择信心值（1～5），**仅可提交一次**。
4. **关闭**：主持人在主持台关闭场次（不可逆，关闭后不可加入或提交）。
5. **公布**：关闭后主持台与参与者页面展示总命中率、按顺序分组与按信心分组的结果；参与者可看到自己的对错与正确杯位。

## 关键规则实现

- **顺序均衡**：加入时在数据库事务内统计六种顺序人数，从人数最少的顺序中随机分配，保证任意时刻各顺序人数差 ≤ 1。
- **盲码唯一**：每位参与者 3 个三位盲码（100–999），在同一事务内校验场次内全局唯一。
- **单次提交**：提交在事务内以 `submitted_at IS NULL` 条件更新，重复提交返回 409。
- **信息隔离**：关闭前参与者接口不返回顺序、正确杯位与统计；主持接口不返回作答与统计。关闭后双方可见汇总。

## 本地开发（不用 Docker）

```bash
npm install
npm start          # http://localhost:3000
```

## 项目结构

```
server.js            Express 路由与接口
db.js                SQLite 初始化、事务与统计
public/              原生前端（首页 / 主持台 / 加入页 / 参与者页）
Dockerfile           多阶段构建（依赖编译 + 精简运行）
docker-compose.yml   一条命令启动，含数据卷
```
